# Memory

Things that were believed here and turned out to be wrong.

Not a changelog and not a design document. `AGENTS.md` says how this repo works;
[`corrections.md`](corrections.md) records the specific wrong turns people and
agents actually took, so the next one does not have to rediscover them.

An entry earns its place when someone confidently believed something false and
it cost time, shipped a wrong claim, or nearly caused a bad change. "I forgot a
flag" does not qualify. "The default value of this flag hides exactly the case
you are looking for" does.

Keep each one to: what was believed, what is true, how it was established, and
the cheapest way to avoid it next time. Cite the file or run that settles it —
an entry no one can verify is worse than no entry.
